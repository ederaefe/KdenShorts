# KdenShorts
AI-powered CLI tool that transforms long-form sermons, podcasts, and talks into pre-cut 9:16 YouTube Shorts &amp; Reels for Kdenlive. Features 20-min zero-drift audio chunking via Gemini Flash, interactive TUI clip curation, and native MLT XML timeline synthesis. 100% local, CPU-friendly, zero GPU required, and free-tier optimized.
